## 🌐 English Description
**Araba Kiralama Sistemi** is a Java-based management application designed to handle car rental operations. This project showcases the use of **Object-Oriented Programming (OOP)** and **Collaborative Development** to build a functional system that tracks vehicle availability, customer reservations, and rental agreements.

### 🚀 Key Features
* **Fleet Management:** Efficiently manage and categorize vehicles within the rental fleet.
* **Reservation System:** Integrated logic for booking, returning, and tracking rental status.
* **Collaborative Project:** Developed as a team effort, demonstrating effective version control (Git) and collaborative coding.
* **OOP Architecture:** Built with clean classes and modular code for easy maintenance.

### 🛠 Tech Stack
* **Language:** Java
* **Tools:** IntelliJ IDEA, Git/GitHub

## 🇹🇷 Türkçe Açıklama
**Araba Kiralama Sistemi**, araç kiralama operasyonlarını yönetmek için geliştirilmiş Java tabanlı bir yönetim uygulamasıdır. Bu proje, araç müsaitliği, müşteri rezervasyonları ve kiralama sözleşmelerini takip eden işlevsel bir sistem oluşturmak için **Nesne Yönelimli Programlama (OOP)** ve **Birlikte Geliştirme (Collaborative Development)** kullanımını sergilemektedir.

### ✨ Öne Çıkan Özellikler
* **Filo Yönetimi:** Kiralık filodaki araçların verimli bir şekilde yönetilmesi ve kategorize edilmesi.
* **Rezervasyon Sistemi:** Rezervasyon yapma, araç iadesi ve kiralama durum takibi için entegre mantık.
* **Takım Çalışması:** Bir ekip çalışması olarak geliştirilmiştir; etkin sürüm kontrolü (Git) ve ortak kodlama becerilerini kanıtlar.

3. Ensure you have the appropriate JDK version configured.
4. Run the application via the main entry point in the `src` folder.
